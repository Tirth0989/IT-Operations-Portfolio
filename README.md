# COMP501 Information Technology Operations Portfolio

This repository contains practical coursework for **COMP501 – Information Technology Operations**. The work demonstrates hands-on skills in computer hardware, operating systems, networking, troubleshooting, virtualisation, cloud infrastructure, and web hosting.

## Repository contents

| File | Description |
| --- | --- |
| [IT Operations Lab Book](Lab-Book/COMP501-IT-Operations-Lab-Book.docx) | A comprehensive practical lab book covering PC hardware, operating-system administration, networking, maintenance, troubleshooting, and security. |
| [Assessment 3 Lab Portfolio](Assessment-3/COMP501-Assessment-3-Lab-Portfolio.docx) | Practical evidence for virtualisation, cloud infrastructure, and Firebase hosting activities. |

## Skills demonstrated

- Computer assembly, disassembly, ESD safety, BIOS/UEFI, boot methods, storage, and RAID
- Preventive maintenance and structured hardware and software troubleshooting
- Network cabling, IP addressing, DHCP, DNS, router and Wi-Fi configuration, and diagnostic tools
- Windows installation and administration, including partitions, users, groups, permissions, devices, monitoring, sharing, remote access, startup, and recovery
- Command-line administration and utilities such as `ping`, `tracert`, and `nslookup`
- Endpoint security using Microsoft Defender, Windows Firewall, BitLocker, and authentication controls
- VirtualBox environments with Ubuntu Server, Apache, and Windows virtual machines
- Cloud concepts and AWS services, including VPC, EC2, RDS, CloudFront, and S3
- Static website deployment using Visual Studio Code, the Firebase CLI, and Firebase Hosting

## Viewing the documents

Open the `.docx` files with Microsoft Word, LibreOffice Writer, or another compatible word processor. Because the lab book contains many screenshots, GitHub may prompt you to download it rather than display a browser preview.

## Privacy

Numeric student identifiers and personal document metadata have been excluded. The author's name is retained only for portfolio attribution.

## Academic use

This repository is published as a personal learning portfolio. It may be used for reference, but the work should not be copied or submitted as another person's coursework.
